# 09 - Reports

# Purpose

The Reports module provides FAST Administrators with operational and
management reports for monitoring Preventive Maintenance (PMS), supplier
performance, checklist findings, Action Plans, and compliance.

Reports shall support on-screen viewing and exporting to Microsoft Excel
and PDF.

Supplier Users shall only be allowed to view reports containing their
own supplier records.

------------------------------------------------------------------------

# General Standards

All reports shall support:

-   On-screen preview
-   Microsoft Excel Export (.xlsx)
-   PDF Export
-   Print-friendly layout
-   Server-side filtering
-   Server-side pagination (for on-screen view)
-   Sortable columns (for on-screen view)

Report exports shall include:

-   Company Logo
-   Report Title
-   Applied Filters
-   Generated By
-   Generated Date and Time
-   Page Numbers (PDF)

------------------------------------------------------------------------

# Common Report Filters

Where applicable, reports shall support:

-   Supplier
-   Site
-   MHE Type
-   Technician
-   PMS Status
-   Action Plan Status
-   Date From
-   Date To
-   Checklist Group
-   Responsible Person

Filters may be combined.

# 8. Supplier Compliance Report

Purpose

Measure supplier compliance based on action plan timeliness.

Filters

-   Period From (year-month)
-   Period To (year-month)
-   Sites (multi-select; defaults to all sites accessible to the user)

Table Columns

-   Supplier
-   District
-   Site
-   Month
-   Action Items Completed
-   Action Items to be Completed
-   Compliance

Compliance Formula

-   Action Items to be Completed: action plans with `timeline_to` in the selected period range (excluding Cancelled)
-   Action Items Completed: subset confirmed on or before `timeline_to`
-   Compliance % = (Completed / To be Completed) × 100
-   Default 100% when there are no action items

Display

-   Table view grouped by Supplier and Month; repeating Supplier, District, and Month values are suppressed within each group
-   **Chart per Month/Supplier** tab: **MHE MONTHLY PMS COMPLIANCE** summary — suppliers on X-axis for a single month; months on X-axis with a series per supplier when the range spans multiple months
-   **Chart per Supplier/Site** tab: per-supplier, per-month bar charts with sites on the X-axis

Exports

-   CSV
-   PDF

# Report Access

## FAST Administrator

Access to all reports.

------------------------------------------------------------------------

## Supplier User

Access only to reports containing their supplier's records.

Supplier Users shall not export or view another supplier's information.

-   Support large datasets
